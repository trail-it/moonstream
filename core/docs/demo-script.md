# 三分钟演示脚本

面向现场/录屏演示。**全部素材离线可复现**：样本固定、分块固定、不依赖网络或 API Key。
时间轴按提案的 0–30 / 30–120 / 120–180 秒结构。

## 准备（演示前）

```bash
node demo/build.mjs     # 构建 wasm-gc 产物并复制到 www/
npx --yes serve .       # 打开 http://localhost:3000/demo/www/
```

浏览器窗口分屏：左侧演示页，右侧终端（已 `cd` 到仓库根目录）。提前把 `demo/www/` 加载好，
但**不要**先点"自动播放"。

## 0–30 秒：问题

- 页面初始状态：左侧「等整段 JSON」显示「（等待完整 JSON…）」，右侧预览是 `<empty>`。
- 一句话："SDK 能收到片段，但应用还不知道哪些字段已经完成，什么时候整个结果才可交付。"
- 点一次「步进一块」（分块 8 字节）。左侧仍然什么都没有；右侧已经出现 `{$` 和 `key tool`。
- 强调：**这些字段不是猜的**，是语法边界已经确认的。

## 30–120 秒：设计

- 30–55 秒：切到终端，展示调用端只有三行：

  ```mbt
  let parser = Parser::new()
  let events = parser.feed(chunk)      // 参数片段字节
  let (tail, result) = parser.finish() // 只有这里能产出可交付结果
  ```

  说明解析库可以独立使用，不依赖任何 Agent 框架。

- 55–80 秒：把分块大小从 8 改成 1，点「自动播放」。汉字和转义跨字节边界时预览照样正确，
  已完成的字段保持不变。切回 8 继续。
- 80–100 秒：终端里跑两个调用交错的最小例子（`core/session/session_test.mbt` 的第一个用例），
  或用 `moon test core --target native --filter "*交错*"` 让测试名出现在输出里，说明
  `Session` 用 `(response, choice, index)` 复合键分流，两条流不会互相污染。
- 100–120 秒：点「模拟截断」。右侧预览保留已解析的字段，状态变成「已取消 / 截断（不可交付）」，
  左侧仍然拿不到结果。说明预览 ≠ 结果。

## 120–180 秒：效果与证据

- 120–145 秒：点「重来」→「自动播放」跑完。状态变「已完成（可交付）」，左侧出现完整 JSON，
  两侧内容一致。强调：只有这一步之后，调用方才能把它交给业务校验或执行。
- 145–165 秒：终端展示证据：

  ```bash
  node demo/check.mjs                      # 端到端：真实 wasm 产物
  moon test --target wasm-gc               # 120 个测试
  moon test --target native                # 127 个测试
  moon bench --target native --release core/perf   # 复杂度基线
  ```

  说明三后端一致、且解析成本与输入长度同阶。

- 165–180 秒：展示仓库结构：主库零 SDK 依赖，`adapters/` 下三个真实 SDK 适配层各自独立成模块。
  结尾一句："MoonBit 承担全部解析与状态判断，浏览器只负责画界面。"

## 常见提问的准备

| 问题 | 回答要点 |
|---|---|
| 和 `@json.parse` 什么关系？ | 我们处理**还没结束**的文档；`CompletedDocument::to_json` 才回到普通 Json。性能上比 `@json.parse` 慢 4–11 倍，代价是逐字段事件、路径与严格校验（见 performance.md）。 |
| 能修损坏的 JSON 吗？ | V1 明确不做。修复会把"猜测"混进模型真实输出；将来若做，必须返回单独的候选与修改记录。 |
| 为什么不用现成的 SDK 自带解析？ | 它们交付的是**文本片段**，`llm-mb` 的注释直接要求消费者等流结束再解析。我们补的正是这一层。 |
| 内存？ | 解析器保留全部原始字节用于构造结果文档，内存与文档同阶；`Preview` 的节点数可查、可清空。 |

## 不要做的事

- 不要在现场展示中声称"性能提升 X%"：本仓库只公布实测基线与方法。
- 不要声称"被官方推荐/被某项目采用"：目前没有任何外部采用记录。
- 不要用实时模型调用作为演示的必要条件。
